## 🌟 Pedagogical Framework

```text
SEE ➔ THINK ➔ DESCRIBE ➔ BUILD ➔ COMBINE ➔ CREATE ➔ ASSESS (25Q) ➔ REFLECT ➔ ANALYZE
```

1. **SEE & THINK (Explore):** Activate sensory awareness using the interactive *School Green Garden* hotspot across the 5 senses (*Sight, Sound, Smell, Touch, and Contextual Taste*).
2. **DESCRIBE (Learn Part B):** Formulate *Adjective Phrases* with three simple patterns:
   - **Pattern 1:** Adverb + Adjective (*very clean, really fresh*)
   - **Pattern 2:** Adjective + Prepositional Phrase (*full of green trees, famous for clean water*)
   - **Pattern 3:** Adjective + To-Infinitive (*pleasant to visit, easy to clean, safe to play*)
3. **BUILD (Learn Part C):** Apply *Simple Present Tense* rules (positive, negative, question forms, and the singular third-person `-s/-es` rule).
4. **COMBINE & CREATE (Learn Part D & E):** Synthesize observations, adjective phrases, and present tense verbs through the interactive *Context Highlighter* (*Our School Garden*).
5. **PRACTICE:**
   - **Level 1 (Controlled):** 10 easy multiple-choice questions focusing on rule recognition.
   - **Level 2 (Guided):** 10 medium questions on sentence building, ordering, and context completion.
   - **Level 3 (HOTS):** 5 questions requiring sentence comparison, evaluation, and paragraph coherence.
6. **ASSESS (Formal 25-Question Examination):**
   - **Difficulty Breakdown:**
     - **LOTS (Lower Order Thinking Skills):** 40% (10 Questions)
     - **MOTS (Medium Order Thinking Skills):** 40% (10 Questions)
     - **HOTS (Higher Order Thinking Skills):** 20% (5 Questions)
   - **Part A — Reading Comprehension (10 Questions):**
     - *Passage 1:* Our Green Schoolyard and Eco-Garden (165 words, 5 Questions: Q1–Q5)
     - *Passage 2:* Rian's Clean Home Backyard Garden (172 words, 5 Questions: Q6–Q10)
   - **Part B — Grammar in Everyday Context (15 Questions: Q11–Q25):**
     - Adjective Phrases & Word Order
     - Simple Present Subject-Verb Agreement & Error Revisions
     - Synthesis and Paragraph Cohesion
7. **REFLECT:** 5 structured self-assessment prompts measuring learning gains, difficulty perception, self-confidence, and future improvement goals.
8. **ANALYZE (Teacher Dashboard):**
   - Class Summary Metrics (*Total Students, Completed, Class Average /25, Highest, Lowest, Avg Reading /10, Avg Grammar /15*).
   - Searchable, sortable Student Roster.
   - Individual Student Diagnostic Modal (Item-by-item breakdown with category, skill, student answer, key, and ✓/✗ indicators).
   - Class Skill Mastery Gauges.
   - Auto-ranked *Most Challenging Questions* for targeted remedial teaching.
   - Export Class Report to CSV and Item Analysis to CSV.
